# physiophoni.cc

This repository serves https://physiophoni.cc, the home of the physiophoni.cc PX-7: a synthesizer and sequencer for the browser where the notes come from physics.

The page is encrypted and opens with an access code. Using the page, and everything it contains once unlocked, is covered by the licence in [LICENSE.txt](LICENSE.txt). That the encrypted file is public here gives no right to use, copy or share it.

`index.html` is the encrypted page and `CNAME` points GitHub Pages at the domain. Everything here is written by an automated build, so changes made in this repository are overwritten by the next release.
